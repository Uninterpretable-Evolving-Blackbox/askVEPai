# Result files behind `work/research/reprompting_proposal.md`

Every table and figure in the proposal is either regenerated by a deterministic harness (no model,
seconds) from tracked inputs, or measured once against Ensembl's VEP and stored here. This directory
holds the harness outputs as they stood on 2026-09-10, so a reader can open the full result instead
of re-running it, and diff a re-run against it.

## Deterministic outputs (no model; regenerate with the command shown)

| file | what it is | proposal section | command |
|---|---|---|---|
| `silence_cost_tier_split.md` | the §4 table: what each fallback costs per output tier, over the 78 clean ablations in `work/preliminary_examples/ablated_queries.json` | §4 | `python work/harness/score_ablations.py --markdown` |
| `silence_cost_species_rerun.md` | the same table over the 155-record rebuild that adds `species` as a fifth target (`ablated_queries_rerun.json`, three seeds, spread zero) | §3 species | `python work/harness/score_ablations.py --file work/preliminary_examples/ablated_queries_rerun.json --markdown` |
| `single_vs_multi_select.txt` | `variant_size_class` single-select-and-asked vs multi-select-guessed-both, RECOMMENDED tier, 23 pure ablations | §3 size | `python work/harness/score_ablations.py --single-select-check` |
| `ask_rate.txt` | how often each candidate policy interrupts, and on which factors, over the 78 clean ablations | §5 | `python work/harness/ask_rate.py` |
| `ask_rate_by_row_shipped.txt` | every case on which the shipped policy raises a question, by row and deleted fact | §5 | `python work/harness/ask_rate.py --by-row --arm shipped` |
| `defaults_evidence_verbose.txt` | 28 checks re-deriving each default (the `region_focus` sweep, the `origin` danger audit, the loss ledger), with the full sweep tables | §3 | `python work/harness/defaults_evidence.py --verbose` |

Inputs these read: `work/preliminary_examples/ablated_queries.json` (124 rewrites, 78 clean),
`work/preliminary_examples/ablated_queries_rerun*.json` (155 rewrites × 3 seeds, adds species),
`work/generation/candidates/iced.json` (the 31 rows), the option catalogue and
`priority_by_factor.json`. All tracked.

not depend on the machine.
